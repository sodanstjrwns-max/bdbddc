# 치료의 안과 밖

2026-10-07 사용자 승인: 진료별 장점·단점·주의사항·적응증·금기증을 환자와 검색엔진이 읽을 수 있게 제공하되 주 메뉴에는 추가하지 않는다. 공개 URL이므로 복제 방지를 보장하지 않는다.

## 기존 콘텐츠와의 관계

기존 종합 가이드 10개, 후회 백서 24개, 비교 백서 34개를 조사했다. 26개 임상 주제를 다루되 새로운 주소는 8개뿐이다.

- 기존 후회 백서 17개는 같은 canonical URL에서 다섯 관점·상황 예시·FAQ·상담 질문·일차 출처를 제공한다. 후회/부작용 검색 의도는 제목과 본문에 유지한다. 출처 없는 확률·확정적인 치료 결과를 옮기지 않는다.
- 기존 임플란트 재수술 장문·그림·영상·FAQ는 보존하고 `#inside-out`에 다섯 관점을 추가한다.
- 재신경치료·치근단수술·잇몸수술·소아·예방·턱관절·구강내과·응급 진료만 `/guide/inside-out/{slug}`를 신설한다.
- 54개 진료 URL(세부 방법·제품 페이지 포함)을 26개 임상 주제로 연결한다. 브랜드·상품별로 같은 원고를 복제하지 않는다.
- 기존 종합·비교 가이드와 나머지 7개 후회 백서는 이번 개편 대상이 아니다. 이번 검증이 그 문서들의 모든 임상 주장 검증을 뜻하지 않는다.

## 원본과 생성

원고·확인일·출처·canonical·진료 연결의 원본은 `src/data/treatment-insights.json`이다. `data/regret-content`의 같은 17개 자료는 예전 생성용이며 공개 원고의 원본이 아니다.

```sh
node scripts/build-treatment-insights.cjs
node scripts/test-treatment-insights.cjs
npm run build:fast
node scripts/test-treatment-navigation.cjs
```

생성기는 공개 HTML, 얇은 런타임 연결 목록 `src/data/treatment-insight-links.json`, 새 주소의 sitemap 항목을 갱신한다. 기존 `build-regret-pages.cjs`도 개편 17개는 예전 원고로 덮어쓰지 않고 새 생성기를 호출한다. 공통 헤더/푸터는 같은 사이트의 재수술 HTML에서 가져오며 주 메뉴 항목을 추가하지 않는다.

금기와 일시적인 보류·조건 조절을 구분한다. 질환명 하나로 치료를 평생 금지하거나 약물 중단·일괄 수술을 지시하지 않는다. 소아·응급·구강내과는 단일 시술이 아닌 진료 영역임을 설명한다. 자료 확인과 의료진 감수는 구별한다.

## 배포 검증

기존 Hono 전체 타입 진단에 72개 오류가 남아 있는 상태에서 시작했다. 새 모듈 strict 검사는 통과하고 전체 진단이 늘어나지 않는지 비교한다. 빌드의 SEO/리뷰 검사를 통과하고 커밋 후 다시 빌드해 실제 수정일을 sitemap에 반영한다. 기존 `seoul-bd-dental` main에 배포한다.

```sh
node scripts/verify-treatment-insights-live.cjs --output /absolute/path/new-live-audit.json
```

26개 URL의 HTTP 200·다섯 본문·canonical·색인 허용·사이트맵, 54개 진료 연결, 8개 신규 경로의 별칭과 미존재 404를 확인한다. 목차·FAQ와 320/390px 반응형 화면도 확인한다. 기존 고민노트 공개 검증을 다시 수행한다. 새 출처나 임상 내용은 수정 시 해당 기관 원문을 다시 확인한다. 검색엔진 접수는 실제 색인과 다르며 Google 사이트맵 반복 재제출은 하지 않는다.
